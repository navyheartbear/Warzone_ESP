# Warzone ESP

Download: soon

Player ESP overlay for Warzone. Built as a standalone visual module.

Features: boxes with size scaling, skeleton, health and armor bars, distance tags, team colors, visibility color switch, loot and vehicle markers, render distance cap.

Two sliders do the tuning: range and brightness. Everything else is a checkbox.

```
loader.exe as admin -> start Warzone -> INSERT
```

Windows 10/11 · Battle.net · streamproof toggle included.
